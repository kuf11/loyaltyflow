# LoyaltyFlow для Эвотор

Нативный Android-проект приложения `LoyaltyFlow` для сценария бонусной скидки на экране оплаты Эвотор.

## Текущее состояние

- зарегистрирован `ReceiptDiscountEvent` для продажи;
- приложение получает управление с экрана оплаты;
- добавлен экран QR/суммы и безопасная кнопка отмены;
- callback Эвотор возвращает скидку после подтверждения;
- backend quote/redeem и авторизация приложения должны быть подключены перед production-сборкой.

Это **не готовый production APK**: нельзя публиковать сборку, пока не подключены серверные endpoint-ы, pairing приложения с кабинетом владельца и не выполнена проверка на тестовом терминале.

## Требования к backend

Нужны отдельные endpoint-ы для native app:

- `POST /api/v1/evotor/app/customer` — QR + сумма, ответ: клиент, баланс, уровень, maxDiscount;
- `POST /api/v1/evotor/app/discount/reserve` — атомарный резерв бонусов;
- `POST /api/v1/evotor/app/discount/commit` — подтверждение после успешного чека;
- `POST /api/v1/evotor/app/discount/release` — возврат резерва при отмене;
- одноразовое pairing-просмотр/отзыв токена приложения.

Баланс из QR нельзя считать достоверным. Окончательное решение должно приниматься сервером, а операции должны быть идемпотентными.

## Сборка

Для локальной сборки нужен Android SDK, JDK 17 и Gradle 8.7+. В CI следует заменить `CHANGE_ME.example` в `BuildConfig.LOYALTYFLOW_BASE_URL` на публичный HTTPS-адрес backend.

До загрузки в Эвотор требуется release-подпись APK и тест на реальном терминале.
