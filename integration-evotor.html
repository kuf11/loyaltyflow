Интеграция с Эвотором

Безопасная синхронизация товаров и остатков через официальное API Облака Эвотор.

Как подключить

1Зарегистрируйте приложение Эвотор

На портале разработчиков создайте приложение с серверным OAuth-сценарием.

2Выдайте минимальные права

Нужны права только на чтение: магазины, товары, остатки и документы. Запись в Эвотор по умолчанию не используется.

3Получите токен доступа

После авторизации пользователя скопируйте access token и вставьте его в форму справа. Токен передаётся только на сервер.

4Синхронизация

После подключения нажмите «Синхронизировать». Товары и остатки обновятся в каталоге LoyaltyFlow, а статус и время последней синхронизации будут видны справа.

Что синхронизируется

ТоварыНазвание, цена, группа
ОстаткиАктуальное количество
МагазиныТочки и кассы

Синхронизация односторонняя: Эвотор → LoyaltyFlow. Ручные товары в каталоге не удаляются. Данные чеков используются для контроля обмена и не начисляют бонусы без привязки чека к клиенту.

Безопасность

  • Токен шифруется на сервере и никогда не возвращается в браузер.
  • Внешние запросы идут только к api.evotor.ru по HTTPS с ограничением времени ожидания.
  • Ответы API ограничены по размеру, токен удаляется из сообщений об ошибках.
  • Доступ к интеграции разрешён только владельцу сессии, запросы изменения защищены проверкой источника и лимитом.
