Интеграция с МоимСкладом

Подключение по официальному JSON API 1.2.

Как подключить

1Создайте отдельный токен

МойСклад → Меню пользователя → Настройки → Токены → + Токен.

2Ограничьте права

Достаточно просмотра сотрудника и точек продаж. Не выдавайте лишние права администратора.

3Вставьте токен

Введите его в форме справа. Сервер проверит аккаунт и загрузит кассы.

4Проверьте список

Найденные точки продаж появятся в блоке подключения.

Безопасность

  • Токен шифруется AES-256-GCM и не возвращается в браузер.
  • API доступен только владельцу с действующей сессией.
  • Адрес МойСклад фиксирован, запрос ограничен 9 секундами.
  • Подключение защищено лимитом попыток и проверкой источника.
