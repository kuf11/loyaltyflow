Конфиденциальность и cookie

Эта страница объясняет техническую логику cookie в LoyaltyFlow.

Какие cookie используются

Используется одна обязательная cookie сессии __Host-lf_session. Она необходима для безопасного входа в кабинет, проверки активной сессии и выхода из аккаунта.

  • HttpOnly — JavaScript страницы не может прочитать токен.
  • Secure — cookie передаётся только по HTTPS.
  • SameSite=Strict — браузер не отправляет её при переходах с посторонних сайтов.
  • Path=/ — cookie действует только в пределах этого сайта.
  • Срок действия — не более 24 часов.

При локальной разработке без HTTPS может использоваться имя lf_session с теми же ограничениями, кроме Secure.

Для чего cookie не используется

Cookie сессии не используется для рекламы, маркетингового профилирования, межсайтового отслеживания или сторонней аналитики.

Удаление

Cookie удаляется при нажатии «Выйти» либо автоматически после окончания срока действия. Без обязательной cookie вход в кабинет работать не может.
